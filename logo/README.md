# Proud Indian logo files

Final logo system (symbol locked, wordmark final, 2026-10-08). Every file here is generated by `logo-tools/` (`bun run logo:rebuild`; `bun run logo:verify` checks a rebuild is byte-identical), except two hand-maintained files that the rebuild keeps: `seals/pi-seal-optimists-ring.svg` and `social/og-default.png` (rendered by `bun run og`). Never redraw, retype or edit these by hand. The full rules are in `brand/Proud-Indian-Brand-Guidelines.pdf` (pages 4–14 and 28); this is the summary.

- **Symbol:** two figures side by side, an adult's arm across a child's shoulder (also reads as π and P + I). The child's head is the only colour.
- **Wordmark:** "Proud Indian" in Anek Latin (width 88, weight 681), outlined and tuned to the symbol. Small-size master (24–40 px): `logo-tools/wordmark/wm-H-small.svg`.

## Lockups

One geometry for all three: the feet stand on the baseline and the adult's shoulder lines up with the cap height (symbol scale = cap ÷ 67). Symbol-to-wordmark gap 0.75 × cap, so the symbol never reads as a third word. The compact lockup has a 0.6 × cap gap and a slightly heavier symbol so it stays legible small.

## Colourways

Pick the file by the ground it sits on.

| Ground | File | Child's head |
|---|---|---|
| Paper or white | full colour (`pi-lockup.svg`) | deep cyan `#0B7FAE` |
| Ink, on screen | `-reversed` (paper shapes thinned 0.25 units for irradiation) | bright cyan `#4CC0EC` |
| Sky / cyan | `-mono` in ink | ink (never a cyan head on cyan) |
| Ink, in print | `-mono` in paper (ink spread does the thinning; don't use the screen-reversed file) | paper |
| One colour only | `-mono` | same as the body |

- Ink `#0F1B24`, paper `#F6F2EA`.
- Never `#4CC0EC` on paper (1.87:1). Never `#0B7FAE` on ink (3.88:1).
- Marigold (`#F4A62A`) is never part of the logo. The wordmark is never cyan.

## Clear space

One adult-head diameter on every side of the visible artwork: 20 units at symbol scale (master grid 100 × 112), about 0.3 × cap height in the lockups.

## Minimum sizes

| Medium | Minimum |
|---|---|
| Screen, symbol | 24 px (at 16 px use only the hand-built favicon) |
| Screen, lockup | 24 px tall (compact lockup below 32 px) |
| Screen, seal | 64 px (below that, use the disc) |
| Print, symbol | 5 mm |
| Print, horizontal lockup | 8 mm tall |
| Rubber stamp or ink seal | 8 mm symbol, 18 mm seal |
| Embroidery | 13 mm symbol, one colour only |

Stamp and embroidery minimums are still to be confirmed with physical proofs.

## Don't

- Stretch, rotate, outline or add shadows.
- Recolour the heads, or add a face.
- Set the symbol on busy photos (use a paper or ink panel, or the disc).
- Retype, track out or redraw the lettering.
- Put stickers, doodles or tape on the logo; the playful layer lives around content.

## React

`@proudindian/design/react` inlines these files: `<Lockup layout="horizontal|compact|stacked|symbol|wordmark" colourway="colour|mono|reversed" accentVar />` and `<Seal kind="main|80g|volunteer|kalakriti|optimists" colourway="colour|mono" />`. Stamp-production and screen-texture seals stay files only.

## On the web

- **Inline SVG (header, menu, footer):** paste the file or put it in a `<symbol>` and `<use href="#…">`. Ink is `currentColor`, so `color: var(--ink)` / `var(--paper)` on the parent recolours it. The child's head is a fixed colour; to let one inline copy follow its ground, change that circle's `fill` to `style="fill:var(--pi-accent,#0B7FAE)"` and set `--pi-accent: #4CC0EC` on ink or `--pi-accent: currentColor` on cyan. Custom properties inherit into `<use>` shadow trees; plain CSS selectors do not.
- **`<img src="….svg">`:** the SVG does not inherit the page's `color`. It renders with the colour on its root (`color="#0F1B24"`, or paper for `-reversed`), so pick the file for the ground.
- **Favicons** (copy `favicon/` to the site root or adjust the paths):

  ```html
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="icon" href="/favicon-32.png" sizes="32x32" type="image/png">
  <link rel="icon" href="/favicon-16.png" sizes="16x16" type="image/png">
  <link rel="apple-touch-icon" href="/apple-touch-icon-180.png">
  <link rel="manifest" href="/site.webmanifest">
  ```

  `favicon.svg` is the hand-built 16 × 16 pixel map drawn as rects; it switches to paper and bright cyan in dark mode. The 16 px PNG is the same pixel art: never replace it with a downscaled master.
